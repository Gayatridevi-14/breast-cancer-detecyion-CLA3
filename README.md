# breast-cancer-detecyion-CLA3
Breast Cancer decetction Using Logistic Regression And Random Forest
Breast Cancer Detection – CLA-3

Project Overview

This project uses machine learning to classify breast cancer cases as malignant or benign.

Dataset

Wisconsin Diagnostic Breast Cancer (WDBC) Dataset.

Algorithms Used

* Logistic Regression
* Random Forest Classifier

Tools and Technologies

* Python
* Scikit-learn
* Pandas
* NumPy

Objective

To build and evaluate machine learning models for breast cancer classification.

Results

Logistic Regression achieved 98.84% test accuracy, while Random Forest achieved 90.70% test accuracy in this experiment.

Base Research Paper

W. N. Street, W. H. Wolberg, and O. L. Mangasarian, “Nuclear Feature Extraction for Breast Tumor Diagnosis,” 1993.

Note: The algorithms implemented here are a separate classroom experiment and do not reproduce the original paper’s method.
